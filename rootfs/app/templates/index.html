스피커가 목록에 안 보일 때 & Music Assistant 연동 가이드

1. Music Assistant의 스피커를 HA 엔티티로 연동하는 방법:
Music Assistant(MA) 웹 화면에 스피커가 등록되어 있더라도, Home Assistant 자체의 설정 > 기기 및 서비스 > 통합구성요소 추가 > 'Music Assistant'가 연결되어 있어야 HA 내부에 media_player.edifier_es300_* 엔티티가 자동 생성되어 검색됩니다.

2. Edifier ES300 2대 스테레오 동기화:
Music Assistant에서 두 스피커를 하나의 'Sync Group' 또는 'Universal Group'으로 묶어둔 뒤, 본 대시보드에서 해당 그룹 엔티티 1개만 체크하면 MA의 딜레이 보정 스테레오 사운드가 적용됩니다.

3. 토큰 수동 입력 (선택 사항):
Supervisor API 통신이 지연되거나 차단된 경우, 상단의 [토큰 설정] 버튼을 눌러 HA 장기 액세스 토큰을 1회 등록해 두면 어떤 환경에서도 안정적으로 통신됩니다.

Home Assistant 토큰 설정

기본 Supervisor API 토큰 외에 장기 액세스 토큰(Long-Lived Access Token)을 등록하여 호스트 포트(8123)로 직접 스피커를 조회할 수 있습니다.
(HA 좌측 하단 사용자 프로필 > 보안 > 장기 액세스 토큰 만들기)
